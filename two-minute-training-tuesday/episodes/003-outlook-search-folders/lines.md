# Episode 003 — lines to read while recording

**New Outlook for Windows.** Classic builds Search Folders somewhere else entirely, so if
you record in classic these lines are wrong — see `script.md`.

Read these in order, out loud, while you drive Outlook. **Pause about a second between
lines and don't pause mid-line** — that pause is the only signal the tooling has for where
one caption ends and the next begins.

Don't worry about the delivery. Your audio is a metronome and never ships; Andrew speaks
the final cut. Wording can drift — the captions get rewritten from what you actually said,
so say it however it comes out.

The last two lines are the outro. Say them, but they get cut from the picture and spoken
over the recap card instead.

---

Welcome to Two-Minute Training Tuesday.
This folder holds every training idea anyone sends me.
Every one of these got here because I moved it by hand.
So the ones I forgot to file aren't here at all.
A Search Folder fixes that. It's a folder that fills itself.
Settings — the gear, top right.
Mail, then Search Folders.
Create new search folder.
Under Organizing mail — Mail with specific words.
The words: Two-Minute Training.
Save.
There it is, under Search Folders.
Every email about it — including the ones I never filed.
Here's the part people miss.
Now back to the Inbox. It's still sitting right there. Nothing moved.
A Search Folder is a saved search, not a place.
That's the difference from a rule. A rule moves mail. This just finds it.
So deleting from here deletes the real email. That's the one catch.
There are more ready to go — unread mail, mail with attachments, large mail.
Classic Outlook can build fully custom ones. This is the version most of us have.
That's it for this week.
Next week: Teams, and how to never lose a message again.
