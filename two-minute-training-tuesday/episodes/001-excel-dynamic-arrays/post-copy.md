> If you have ever copied a column out of an export, run Remove Duplicates,
> sorted it, and then done the identical thing again the following month: this
> one is for you.
>
> Three Excel functions, 1:49:
>
> - `=UNIQUE(range)` — the distinct values in a column, no Remove Duplicates
> - `=SORT(UNIQUE(range))` — same list, alphabetical
> - `=FILTER(table, column = criteria)` — every row matching a condition, where
>   the condition can point at a cell. Change the cell, the whole report redraws.
>
> All three write their own results into as many cells as they need, so you never
> drag a formula down again.
>
> Demo workbook is attached — same 380-row export from the video, so you can
> break it without consequences.
>
