# Style guide

Consistency is what makes a series feel like a series instead of a folder of
screen recordings. These are the defaults; break one only when the tip needs it.

## Runtime

| | |
| --- | --- |
| Target | 1:45 |
| Hard ceiling | 2:00 |
| Title card | 2.5 s |
| Recap card | 4.0 s |
| Content | ~1:40 |

If a tip cannot fit, it is two episodes. That is a feature — the backlog gets
longer and each Tuesday gets simpler.

## Structure

Every episode follows the same five beats. Viewers learn the shape and relax
into it.

1. **The pain (0:00–0:12)** — Name the annoying thing, in the audience's own
   words. "Every month you paste the vendor list into a new tab and re-sort it."
2. **The payoff (0:12–0:20)** — Show the finished result *before* teaching it.
   "Here's the same list, and it updates itself. Watch."
3. **The doing (0:20–1:25)** — Type it live. Narrate what you type, not why it
   works internally.
4. **The proof (1:25–1:40)** — Change the source data and show the result move.
   This is the moment that sells it. Never skip it.
5. **The recap (1:40–1:45)** — The card. Read the formula names aloud once.

## Voice

- Second person. "You paste," "you'll see," not "one can."
- Present tense. "I type UNIQUE," not "I'm going to be typing."
- No apologising, no hedging, no "this is a bit of a rabbit hole."
- Say the keystroke out loud when you press it: "Ctrl + Shift + V." People are
  listening while looking at another window.
- Read formula names as letters at first mention if they're likely to be
  misheard.

## On screen

| Element | Standard |
| --- | --- |
| Resolution | 1920×1080, 16:9 |
| Excel zoom | 130–150% |
| Ribbon | Collapsed (Ctrl+F1) unless the tip is about a ribbon control |
| Theme | Light mode. Dark mode Excel screenshots read badly when embedded in Teams and SharePoint. |
| Cursor | Move deliberately. No idle circling while you talk. |
| Data | Demo workbook only. Never a live production file. |
| Captions | Always on, always burned in, always proofread |

## Audio

- Mic input peaking around two-thirds, never clipping.
- No music. On a 120-second video, music is competition, not production value.
- Cut every silence longer than about one second, except the deliberate beat
  after the proof step.

## File naming

```
TMTT-###-Short-Kebab-Title.mp4      TMTT-001-Excel-Dynamic-Arrays.mp4
TMTT-###-raw.mp4                    TMTT-001-raw.mp4          (keep 30 days, then delete)
TMTT-###-title.png                  TMTT-001-title.png
TMTT-###-recap.png                  TMTT-001-recap.png
```

Episode numbers are permanent and never reused, even if an episode is retired.
"Go watch #004" has to keep working.

## Episode titles

Name the outcome, not the feature. The feature name goes in the subtitle.

| Write this | Not this |
| --- | --- |
| Stop copy-pasting your vendor list | An introduction to UNIQUE |
| Find that attachment in four seconds | Outlook search operators |
| Never lose a Teams message again | Using saved messages in Teams |
| Make one number and let Excel do the rest | Understanding spill ranges |

## Accessibility

Not optional, and cheap to get right.

- Burned-in captions, proofread.
- Never rely on colour alone to point at something — say the cell reference out
  loud: "cell H1", not "the green one".
- Keep contrast high on title and recap cards.
- Post a one-paragraph written summary alongside every video, with the formula
  or the click path in text. Some people will never press play, and search
  indexes text, not video.
